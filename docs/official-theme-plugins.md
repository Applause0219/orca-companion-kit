# 官方主題外掛對照表

Orca 從 v1.4.245 開始支援**圖示主題**和**語法高亮**外掛，v1.4.246 以上還有**只放主題檔的 ANSI 配色外掛**。這些外掛和這個 kit 注入的樣式有一部分管的是同一塊，可能疊在一起，也可能被 Orca 的設定蓋掉。這份文件列出哪些部分官方外掛已經能做、哪些還是得靠注入，以及哪些可以改成純主題檔。

> 外掛的檔案格式、設定的名稱以你手上那一版 Orca 的說明為準。下表「kit 現在怎麼做」那一欄是照這個 repo 的程式寫的，由 `test/theme-plugins-doc.test.mjs` 把關；「官方外掛」那一欄是依 Orca 的版本說明整理的，Orca 改版後請再對一次。

## 對照表

| 部分 | 官方外掛（版本） | kit 現在怎麼做 | 會不會重疊 | 建議 |
| --- | --- | --- | --- | --- |
| **檔案圖示** | 圖示主題外掛（v1.4.245+） | 沒做，不注入 | 不會 | 交給官方外掛 |
| **語法高亮** | 語法高亮外掛（v1.4.245+） | 只改 Monaco 外框用的 `--vscode-*` 變數（編輯器底色、行號、目前行、迷你地圖），不改程式碼本身的顏色 | 會：外掛若也設了編輯器底色，主題結尾那段 `.monaco-editor` 規則有 `!important`，會把它蓋掉 | 程式碼顏色交給外掛；kit 只留「編輯器底色跟外框一致」這一小段，並讓使用者能關掉 |
| **終端機 ANSI 十六色** | 只放主題檔的 ANSI 配色外掛（v1.4.246+） | `terminal/<主題 id>.json`，啟動器經由 Orca 的設定 API 寫進 `terminalCustomThemes`，再把 `terminalThemeDark` 設成它；換走主題時還原原本的值 | 會：兩邊改的是同一個設定，後寫的贏。套用 kit 主題時，使用者在設定裡選的外掛配色會被換掉，換走時才還原 | 這份 JSON 本來就是純資料，最適合改包成官方外掛的主題檔，kit 只負責「選它」或乾脆不碰 |
| **色彩模式（亮／暗）** | Orca 自己的設定，外掛的主題檔也能分亮暗 | 主題 CSS 寫在 `html.dark` 底下、加 `color-scheme: dark`；終端機只改 `terminalThemeDark`，亮色模式不管 | 會：使用者切到亮色時 kit 的主題整個不生效，終端機也停在官方的亮色配色 | 跟著 Orca 的設定走，不要強制；要支援亮色就在主題裡另寫 `:root` 那一份 |
| **介面外框配色** | 沒有 | 主題 CSS 改 Orca 的 CSS 變數（`--background`、`--sidebar*`…），見 [themes.md](themes.md#orca-的-css-變數) | 不會 | 還是得靠注入 |
| **游標** | 沒有 | `custom-cursor` touch 加屬性，主題 CSS 換 `cursor` | 不會 | 還是得靠注入 |
| **通知音效** | 沒有 | `theme-sound` touch 換掉 Orca 的通知音 | 不會 | 還是得靠注入 |
| **圖片素材、片段** | 沒有 | `assets/<主題 id>/` 變成 `--asset-*`；`snippets/*.css` 疊加 | 不會 | 還是得靠注入 |
| **寵物、打字火花、其他 touch** | 沒有 | `touches/*.js`，經由 CDP 在每個視窗載入前注入 | 不會 | 還是得靠注入 |
| **Ctrl+Alt+T 主題選單** | 沒有（官方外掛在 Orca 設定裡選） | 注入的選單，換主題、開關 touch 和片段 | 部分：兩個地方都能換終端機配色，見上面 ANSI 那一列 | 還是得靠注入 |

## 哪些可以改成純主題檔

注入靠的是 Orca 內部的 DOM 和設定名稱，Orca 改版時最容易壞的就是這些。官方外掛的主題檔是 Orca 自己會讀的格式，改版時由 Orca 負責相容。所以原則是：**官方能做的就交給主題檔，注入只留官方做不到的。**

1. **終端機配色。** 最值得先改。`terminal/<主題 id>.json` 已經是純資料，改包成 ANSI 配色外掛的主題檔，就不必再經由設定 API 寫 `terminalCustomThemes`、`terminalThemeDark`，也不用在設定 API 不通時退回重新載入主視窗（[themes.md](themes.md#終端機配色)）。kit 主題可以只標「建議搭配哪一套外掛配色」。
2. **程式碼顏色。** 現在沒做，以後想做就直接寫成語法高亮外掛的主題檔，不要用注入改 Monaco 的 token。
3. **檔案圖示。** 同上，直接用圖示主題外掛。
4. **Monaco 外框變數。** 如果語法高亮外掛的主題檔能一起設編輯器底色、行號這些顏色，就把四套內建主題結尾的 `.monaco-editor` 那段搬過去；做不到就留著，但拿掉 `!important`，讓外掛的值優先。

介面外框配色、游標、音效、寵物和其他 touch 目前沒有官方的對應，還是得靠注入，照 [performance.md](performance.md) 的規則寫，並靠啟動器的[改版檢查](themes.md#dom-掛點)提早發現掛點不見。

## 改之前要先確認的事

- 外掛主題檔的格式：ANSI 配色外掛的欄位是否和 Orca 的 TerminalColorOverrides 一樣（`background`、`foreground`、`black` … `brightWhite`），能不能直接沿用現在的 JSON。
- 外掛選的配色存在哪個設定裡，是不是也是 `terminalThemeDark`；如果是，kit 套用主題時就不該再改它。
- 語法高亮外掛管不管編輯器底色。
- 舊版 Orca（v1.4.245 以前）沒有外掛，現在的注入路線要留著當退路。
